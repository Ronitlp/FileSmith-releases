# FileSmith for Windows

Drag a file, tap **Shift**, and a wheel of formats and tools opens under your cursor. Convert and edit photos, PDFs, video, audio and documents, entirely on your own PC.

- **Download:** https://ronitlp.github.io/FileSmith-releases/ (or the newest file under [Releases](https://github.com/Ronitlp/FileSmith-releases/releases/latest))
- **What's new:** https://ronitlp.github.io/FileSmith-releases/changelog.html

This repository holds only the installers, the update information (`latest.json`, signed in `latest.json.sig`) and the website.
